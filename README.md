# FixHub

FixHub is a web platform developed to help users find authorized technical assistance centers based on product categories and geographical location.

## Features

- User authentication
- Search assistance centers
- Product categories
- Geographic filtering
- Administrative management
- Relational database

## Technologies

- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Architecture

The application follows the MVC pattern provided by Laravel.

Main components include:

- Authentication
- Controllers
- Models
- Database migrations
- Seeders
- Blade templates
